计算方法与全部假设
  1. 供款：雇员、雇主各按有关收入的 5% 作强制性供款。有关收入上限为月薪 30,000 港元（每方每月供款上限 1,500 港元）；下限为月薪 7,100 港元，低于此数雇员无须供款、雇主仍须供 5%。这三个数字是法定参数，不存在于 data/funds_latest.json 数据集中（该数据集只有基金层面的费用与回报字段），因此在代码里写死，法例修订时需同步更新。自愿性供款、特别自愿性供款不在模型内。
  2. 年期：退休年龄固定 65 岁，供款月数 =（65 − 当前年龄）× 12。
  3. 复利：月度复利。净年化回报 = 预期年化回报率 − FER；月利率 i = (1 + 净年化)^(1/12) − 1，即 12 个月复利后恰好等于净年化。
  4. 供款时点：供款在每月月末投入（普通年金），逐月迭代 余额 = 余额 × (1 + i) + 月供款；对应闭式解 FV = C × ((1+i)^n − 1) / i。
  5. FER 的用法：把 FER 整体当作对年化回报的扣减。实际上 FER 是按资产净值收取、且本身每年会变；这里假设全程不变。
  6. 不包含：现有累算权益（起始余额按 0 计）、薪金增长、通胀、基金转换的时间差与价格波动、回报率的年度波动、受托人可能收取的其他费用。
  7. 因此：输出是在上述假设下的数学推算，用来比较「同样条件下费率差距的量级」，不是对任何基金未来金额的预测。

计算核心在 docs/assets/fee-math.js，含 3 组手算验证用例的测试在 docs/tests/fee-math.test.js（node docs/tests/fee-math.test.js）。

本页只呈现数学结果。费率高低并非选择基金的唯一考虑，基金种类、资产配置、风险级别、保证条款与个人情况同样会影响结果，本站不就任何基金或计划作出任何意见。
